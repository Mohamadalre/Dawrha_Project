دورها — نماذج الواجهات Prototype

نماذج HTML لكل واجهة في الأنظمة الثلاثة، مرفقة بمرجعي الـ API التفصيليين: المرجع الكامل (324 endpoint + Socket.IO) ومرجع طلبات التجميع والشحنات (37 endpoint).

الواجهات محاكاة (Mockup) — كل زر يعرض الطلب الحقيقي المرتبط به بدون اتصال فعلي بالخادم.

📘 دليل الفلوات التفصيلي

شرح كامل لسير العمليات: إنشاء طلب من مستخدم → فرز للسائق → إسناد → جمع → نقل → تسليم، خطط المؤسسات، انضمام السائقين واعتماد Odoo، والمزيد — كل خطوة مربوطة بالشاشة المقابلة.

📱 تطبيق المستخدم CITIZEN · INSTITUTIONS · FACTORY · EXTERNAL_PARTNER

تسجيل، تصفح المنتجات، سلة، طلب جمع، تتبع مباشر، نقاط ومحفظة.

تسجيل الدخول إنشاء حساب تحقق OTP الرئيسية السلة طلب جمع جديد طلباتي وتتبعها ملفي الشخصي

🚛 تطبيق السائق COLLECTOR

تسجيل دخول، إنهاء ملف (معلومات/موقع/وثائق)، جولة الجمع، استلام الشاحنة، الشحنات، تغيير الوردية، بث مباشر للموقع عبر Socket.IO.

تسجيل الدخول إنهاء الملف (Onboarding) الرئيسية الجولة 📦 الشحنات ملفي

ملاحظة: قبول السائق/رفضه يتم في Odoo عبر webhook — لا يملك الأدمن صلاحية تغيير حالة السائق مباشرة.

🖥️ تطبيق الأدمن ADMIN

لوحة تحكم، إدارة حسابات، طلبات الجمع والإسناد اليدوي، أسطول وورديات (تتبع مباشر)، الشحنات، كتالوج وتسعير، تقارير.

تسجيل الدخول لوحة التحكم الحسابات طلبات الجمع الأسطول والورديات 📦 الشحنات الكتالوج والتسعير التقارير

🔌 نقاط الربط المباشر (الخادم المحلي)

هذه النماذج تحاكي الـ API. لتشغيلها فعليًا ضد الخادم المحلي على المنفذ 3000، يجب ربط كل استمارة بـ fetch. المسارات الحقيقية:

POST /api/v1/auth/login/user-app · POST /api/v1/auth/login/collector-app · POST /api/v1/auth/login/admin
POST /api/v1/auth/register/citizen · POST /api/v1/auth/otp/verify
POST /api/v1/onboarding/collector/location · POST /api/v1/onboarding/collector/upload-doc (multipart)
POST /api/v1/admin/collection-requests/:id/assign · PATCH /api/v1/driver/collection-requests/:id/{accept|arrived|collected|delivered}
POST /api/v1/shipments · GET /api/v1/shipments · PATCH /api/v1/shipments/:id/{depart|deliver|cancel} · GET /api/v1/shipments/admin/all
Socket.IO: /tracking (truck:location · truck:stop · admin:subscribeAll) · /collection (request:assigned · request:updated)
