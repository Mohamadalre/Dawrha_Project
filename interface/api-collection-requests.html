🚛 API طلبات التجميع — كلا Documentation

مرجع شامل لـ 26 endpoint تخص طلبات التجميع والتوزيع + 2 namespace Socket.IO للبث المباشر، مقسم حسب الدور: المستخدم (إنشاء وإدارة الطلبات)، السائق (الجولة والتنفيذ)، الأدمن (الإسناد والإعدادات والتقارير)، Socket.IO (تتبع مباشر + تحديثات فورية).

ملخص

👤 المستخدم 4 🚚 السائق 6 🔧 الأدمن 16 📡 Socket.IO 2 ns POST 7 GET 10 PATCH 8 DELETE 1
الرموز: :id معرّف UUID للطلب · كل المسارات تبدأ بـ /api/v1 · قنوات Socket.IO: /tracking و /collection

💡 ملاحظات التنفيذ في الواجهة

// 1. تحميل المكتبة
<script src="https://cdn.socket.io/4.7.5/socket.io.min.js"></script>

// 2. الاتصال بنطاق التتبع
var socket = io('http://localhost:3000/tracking', {
  auth: { token: localStorage.getItem('daw_token') }
});

// 3. إرسال الموقع كل 5 ثوانٍ
setInterval(function () {
  navigator.geolocation.getCurrentPosition(function (pos) {
    socket.emit('truck:location', {
      truckId: TRUCK_ID,
      lat: pos.coords.latitude,
      lng: pos.coords.longitude
    }, function (res) { console.log(res); });
  });
}, 5000);

// 4. الاتصال بنطاق العروض (السائق)
var coll = io('http://localhost:3000/collection', {
  auth: { token: localStorage.getItem('daw_token') }
});
coll.on('request:assigned', function (data) {
  console.log('عرض جديد!', data);
  renderTour();
});
