🚛 API طلبات التجميع — كلا Documentation

مرجع شامل لـ 41 endpoint تخص طلبات التجميع والتوزيع والشحنات + 2 namespace Socket.IO للبث المباشر، مقسم حسب الدور: المستخدم (إنشاء وإدارة الطلبات + التسليم الفوري)، السائق (الجولة والتنفيذ والشحنات)، الأدمن (الإسناد والإعدادات والتقارير)، Socket.IO (تتبع مباشر + تحديثات فورية). ⚡ الطلبات الفورية (IMMEDIATE) تُسند لمdriver بشكل متزامن أثناء الإنشاء — لا queue.

ملخص

👤 المستخدم 7 🚚 السائق 14 🔧 الأدمن 16 📦 الشحنات 5 📡 Socket.IO 2 ns POST 10 GET 15 PATCH 13 DELETE 1
الرموز: :id معرّف UUID للطلب · كل المسارات تبدأ بـ /api/v1 · قنوات Socket.IO: /tracking و /collection
